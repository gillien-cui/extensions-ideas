# Exercise Library

One file per exercise, all in the same format: what it targets, a demo link (photos + video), setup, steps, cues, common mistakes, and easier/harder options.

Back to the plan: [`workout-plan.md`](../workout-plan.md)

> **About images:** each file links to a demo page with photos/video from the ACE or NASM exercise libraries. Images weren't embedded because the environment these were written in couldn't download them. Embedding them is a good job for the app version.
