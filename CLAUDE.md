# Extensions Ideas

This workspace is a collection of research, analysis, and ideas for browser extensions and independent software products.

## Project Structure

- Markdown files (`.md`) contain research notes, analyses, and product ideas
- `tasklist.md` — task tracking for ongoing work

## Guidelines

- Keep research documents well-structured with clear headings
- Use markdown formatting consistently
- When adding new ideas, create a dedicated `.md` file with a descriptive name
- Prefix filenames with the product/extension name for easy identification
